Use a skill identidade-visual para aplicar a identidade visual Multiplica neste sistema.
O sistema se chama <NOME> (a marca da sidebar fica "Beyond<NOME>").
Siga o Padrão Multiplica à risca e em TDD: copie os testes primeiro, veja falhar, depois o código.
Troque o index.css, ligue o tema sem piscar no index.html e coloque as rotas logadas dentro do AppShell.
Substitua qualquer cor solta das telas existentes por tokens e use lib/formatos.ts para moeda, data, CPF e CNPJ.
No fim, rode pnpm lint, pnpm typecheck, pnpm test e pnpm build, abra a tela nos dois temas e mostre o checklist de pronto.
