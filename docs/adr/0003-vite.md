# ADR 0003 — Vite como scaffolding do frontend

## Status
Aceito

## Contexto
O PRD define o produto como uma aplicação web desktop interna, sem requisito de SEO ou de renderização no servidor.

## Decisão
Vite + React + TypeScript, como SPA pura.

## Alternativas consideradas
- **Next.js:** traz SSR e roteamento por arquivo, mas nenhum dos dois é necessário aqui — seria complexidade e superfície de configuração adicional (data fetching no servidor, RSC) sem benefício para um app atrás de login usado por até 10 pessoas.

## Consequências
- Roteamento via `react-router` (client-side).
- Toda chamada de API é feita do browser, autenticada via JWT — não há necessidade de lidar com segredos no servidor de renderização.
